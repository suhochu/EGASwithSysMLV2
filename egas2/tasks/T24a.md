1. AQ5(표현력·추적성·ISO): 독립성 요구와 FFI 제약을 Common 메타데이터 또는 Lwb 제약 요소로 만든다. doc 주석으로만 있던 내용을 요소로 승격하고 CCF 한계(OI-27)는 한계로 남긴다. 값은 pilotAssumed·tbd로 표시한다.
2. OI-12(표현력): SG→SYSR `derivedFrom` 문자열을 `#derivation` 등 실제 관계로 바꾸고 `HardwareFailureConcern`을 `frame`하는 SHR 연결을 정한다. Shr 변경이 필요하면 사용자에게 먼저 묻는다.
3. AQ7(추적성): 시나리오→SYSR 직접 `#refinement`를 추가해 SC→LC 범위를 좁힌다(D-26 R5). Scn·Beh·Sysr 변경이므로 GATE 승인 후 실행한다.
4. 일관성: `lint.py`에 규칙을 추가한다. 후보는 SG→SYSR 관계 누락, SYSR→검증 커버리지(OI-28·29), UF·FN·LC `satisfy` 끊김이다. 각 규칙에 `test_lint.py` fixture를 둔다. OI-01(K4 정확 일치)은 수정 범위가 작을 때만 함께 닫는다.
5. 검증 공백: SYSR 5개와 TSR 2개의 검증 케이스를 기존 `verification def` 양식으로 추가한다. 총 모델 줄이 400줄을 넘을 것 같으면 멈추고 T24b로 분할한다.
6. 갱신: AqResults_T21b.md의 AQ5·6·7 답, OPEN_ISSUES(닫힌 항목 resolved 제안), REGISTRY.
