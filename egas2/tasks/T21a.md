# T21a · L3 셧오프 경로와 CCF (OI-20)

## 목적

OI-20의 세 한계를 모두 모델에 반영한다: ① L2 경로가 L1 모드 채널에 의존하는 것을 없애고, ② L3 독립 모니터링·셧오프 경로를 논리 컴포넌트로 추가하고, ③ L1·L2가 공유하는 입력과 같은 ECU의 공통원인 고장(CCF)을 모델링한다. 그 근거를 A-02·A-06 판정용으로 정리한다. MAP.md T21a 행(D-27이 T21을 둘로 나눔). D-23의 L3 LC 없음, D-25 ②③, D-26 R6을 D-27이 뒤집었다.

## AI가 할 일

1. **설계안을 표로 만들어 모델에 쓰기 전에 사용자에게 보인다(GATE).** 항목: 새 UF·FN·LC 이름과 입출력, 새 FSR(SReq-07)의 부모 SHR·SG 연결, 셧오프 반응의 안전 상태 단계(`SafeStateStage`), L3 안전 메커니즘(kind, `monitoringLevel` L3), CCF 표현 방식, 예산 변화. 사용자가 승인하기 전에는 모델을 고치지 않는다.
2. ① `modeChannel` 제거: Fbb UF-03·UF-07의 `in modeChannel`과 `egasUf` flow 두 개, Fwb FN-06의 `in modeChannel`과 `bind`, Lwb `l2Reaction`·`l2Output`의 `modeChannelIn`과 연결 2건, 143행 주석. UF-05·FN-10·`l1Control.modeChannelOut`은 L1 안이라 유지하고 `l1Control.modeChannelOut`이 남는 연결이 없으면 포트도 정리한다. 모드는 `activeModes`로 표현한다.
3. ② L3: SYSR 1개(예: `sysrControllerMonitoring`, FSR 후보. ASIL은 상속 기본이고 근거는 e111·e127), UF 1개와 FN 1~2개(Q&A 질문 처리·Q&A 응답 확인, 셧오프 요청), Lwb에 `L3MonitorComponent`(`:> AsilAllocatedComponent`, `@SafetyMechanism` monitor·L3)와 포트·채널(독립 경로로 `l2Output` 또는 출력 단의 셧오프 입력에 연결). L3 경로는 L1·L2 어느 쪽도 거치지 않게 한다. Q&A 값은 Common `qnaCycleMax`·`qnaQuestionCountMin`을 인용만 하고 단계별 ms·WCET은 쓰지 않는다.
4. ③ CCF: 공유 입력 포트(`accelerationInput`·`sensorInput`)와 같은 ECU를 공통원인으로 표시하고 영향 받는 LC·완화 상태를 적는다. 표현은 GATE에서 고른다(후보 A: Common에 `FailureMode`(mode·effect·propagatesTo·detectedBy, DESIGN_MAP 2절) 최소 추가. 후보 B: 기존 `FreedomFromInterference`·`SafetyMechanism` 필드 재사용). CCF를 모델링해도 독립성이 입증되는 것은 아니므로 ASIL 분해는 하지 않는다.
5. 안전 값은 모두 `@ValueStatus`와 `@SourceRef`를 갖고 근거 없는 값은 pilotAssumed 또는 tbd로 둔다(`reviewed` 금지). 새 LC·FSR의 ASIL, L3 메커니즘 배정, 셧오프 상태를 승인 필요 목록으로 만든다.
6. A-02 조건 근거를 갱신한다: 정상 경로와 L3 경로가 독립인지, L1 고장·L2 고장·공통원인 각각에 대해 FTTI 안에 위험이 제거되는 구조인지 근거만 정리한다. 충족 판단은 AI가 하지 않는다. OI-20은 처리 결과를 적고 상태를 사용자가 정한다.
7. 새 요소를 Registry에 등록하고(`concept-registry-guard`) K10 사슬(GP-A·GP-B)과 K15 고아 0, `check_namespace.py`·`lint.py`·`syside check egas2/model`을 확인한다. 안전 판단이 들어갔으므로 `safety-reviewer`에게 검토를 맡기고 지적 사항을 처리하거나 OI로 올린다.
8. `/close-task`를 실행한다. handoff `T21a.md`는 80줄 이내. 필요하면 보고서는 `handoffs/L3Ccf_T21a.md`로 둔다(D-18).
