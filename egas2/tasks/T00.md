# T00 · 스캐폴드 설치와 검증 (사용자)

## 목적
Copilot이 Task를 실행할 수 있는 환경(지침, 프롬프트, 메모리, 검사 스크립트)을 같은 저장소의 `egas2/`에 설치하고, 규칙이 실제로 작동하는지 확인한다.

## 사용자가 할 일
1. 스캐폴드의 `.github/`와 `egas2/`를 **저장소 루트**(`.git`이 있는 폴더)에 복사한다. `.github/copilot-instructions.md`가 이미 있으면 덮어쓰지 말고 내용을 합친다. Python 3.9 이상이 필요하다.
2. 통합 브랜치를 만든다: `git switch -c egas2-pilot`. 이후 Task 브랜치는 모두 여기서 갈라지고, 각 Task가 끝나면 사용자가 여기로 머지한다.
3. 검사 스크립트 세 개를 실행한다.
   - `python egas2/tools/check_namespace.py` → `errors: 0`
   - `python egas2/tools/legacy_inventory.py` → LEGACY_INVENTORY.md, MIGRATION_MAP.csv, LEGACY_HASHES.json 생성. **한 번만 실행한다.** 이 시점의 레거시가 "레거시 무변경 검사"의 기준이다.
   - `python egas2/tools/kpi.py --task T00 --ide-errors 0` → `PASS`
4. VS Code를 저장소 루트에서 열고 Copilot Chat을 Agent 모드로 둔다. 입력창에 `/`를 쳐서 `start-task`, `close-task`, `plan-next-task`, `gate-review`가 보이는지 확인한다.
5. **진단 확인(중요)**: `egas2/model/00_Common/_smoke.sysml`을 만들고 아래 내용을 넣는다. 3번째 줄은 일부러 넣은 문법 오류다.
   ```
   package EgasArch_Common_Smoke {
       part def Smoke;
       part def 123bad;
   }
   ```
   - Syside가 Problems 패널에 오류를 표시하는지 본다. 표시되지 않으면 Syside가 `egas2/model`을 읽지 않는 것이므로 프로젝트 설정을 먼저 해결한다.
   - Copilot Chat(Agent)에 "egas2/model/00_Common/_smoke.sysml의 오류(진단)를 읽어서 알려 줘"라고 입력한다. 오류를 읽으면 STATE.md의 "IDE 진단 방식"에 `agent`, 못 읽으면 `user-report`라고 적는다.
   - 확인이 끝나면 `_smoke.sysml`을 지운다.
6. Syside에서 레거시를 열어 컴파일 오류·경고 수를 STATE.md의 "레거시 컴파일 기준선"에 적는다.
7. 커밋한다: `git add .github egas2 && git commit -m "egas2: T00 scaffold"`
8. Copilot Chat에서 `/start-task T01`을 실행한다.

## 완료 기준
검사 스크립트 세 개가 오류 없이 실행되고, 슬래시 명령 네 개가 보이며, Syside가 `egas2/model`의 문법 오류를 표시하고, STATE.md에 기준선·진단 방식·통합 브랜치가 적혀 있고, 커밋이 되어 있다.

## 레거시를 정당하게 고쳐야 할 때
레거시 파일 변경은 KPI K7이 HARD로 막는다. 팀이 레거시를 실제로 수정해야 하면 수정 후 `python egas2/tools/legacy_inventory.py --rebaseline`을 실행하고 DECISIONS.md에 사유를 기록한다.
